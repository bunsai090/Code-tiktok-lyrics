# Lyrics Code TikTok

A simple collection of Python scripts containing lyrics/content used for TikTok projects.

**Quick Start — Simple step-by-step (Windows)**

1. Open PowerShell and go to the project folder:

```powershell
cd "c:\3RD YEAR SECOND SEM\Lyrics code tiktok\Code-tiktok-lyrics"
```

2. (Optional) Create and activate a virtual environment:

```powershell
python -m venv venv
venv\Scripts\activate
```

3. Run a script (example):

```powershell
python fortnight.py
```

4. To run a different file, replace the filename in the command (e.g. `python lorde.py`).

That's it — three commands and you're running the scripts.

**Requirements:**
- Python 3.8 or later (recommended 3.10+)

**How to run (Windows):**

1. Open a terminal and change directory to the project folder (`Code-tiktok-lyrics`).
2. (Optional) Create and activate a virtual environment:

```powershell

venv\Scripts\activate
```

3. There are no external dependencies currently. Run the script you want directly:

```powershell

python "Lily of The Valley.py"
python "lorde.py"
python "secretdoor.py"
```

Replace the filename with the script you want to run.
